How Forward Chaining Works:

  1. User preferences are asserted as facts into Working Memory.
  2. The Inference Engine iterates through all active rules (sorted by priority).
  3. Each rule's condition set is evaluated against current Working Memory facts.
  4. If ALL conditions of a rule match → the rule fires and its action is asserted.
  5. Menu items are then filtered to find those satisfying at least one fired rule.
  6. Results are scored and ranked by confidence. Non-vegetarian items are excluded for vegetarian users (hard constraint).
